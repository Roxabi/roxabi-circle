# Security

Report a vulnerability in this Kit by email: [team@unkillablecompanies.com](mailto:team@unkillablecompanies.com).

That mailbox is the disclosure channel. Do not open a public issue, pull request, or discussion for a vulnerability, and do not put exploit details in one.

## What to send

Send a short private report:

- the Kit area involved, and a version or commit if you know it
- impact, without a public exploit write-up
- a minimal sanitized reproduction

Omit raw logs, client data, and secret values. An App or User identifier is not automatically a secret; omit secret values anyway.

This file names the contact. It does not promise a response time.

Maintainers handle the report in private. A published fix, when there is one, follows [CONTRIBUTING.md](CONTRIBUTING.md). The public write still uses a public-safe payload. Vulnerability detail stays private unless maintainers explicitly approve a coordinated disclosure after the fix.
