# Vision — Roxabi Circle

## Intent

Créer un **cercle fermé** de gens **très tech côté IA**, avec une ADN **open source et partage**. Pas un serveur Discord générique « AI hype » : un filtre d’entrée qui prouve que la personne **produit du code public**, s’intéresse à l’IA (comme sujet ou comme outil), et est active.

## Pourquoi GitHub comme porte

- preuve d’identité (OAuth) → ce profil est bien le leur
- signal de contribution réelle (public)
- aligné avec l’ADN annoncé (« Préparez vos github »)
- scorable sans subjectivité humaine au premier filtre

## Proposition de valeur

| Pour le membre | Pour le cercle |
|---|---|
| pair-group de haut niveau, gratuit | densité de conversation élevée |
| lives 1–2 sem, sujets techniques durs | moins de noise / tourists |
| confrontation de croyances, stack, harness | bar d’entrée crédible (OSS) |

## Positionnement

- **C’est** : cercle d’experts / builders IA + OSS
- **Ce n’est pas** : cours, job board, crypto-community, support no-code
- **Ton** : direct, technique, humble, anti-hype

## Gouvernance (évolution)

1. **MVP** — scoring auto accept/reject + opérateur (override manuel)
2. **P2P** — membres existants peuvent parrainer / second vote si borderline
3. **Teams** — si scale : équipes thématiques (harness, MCP, product AI, …)

## Exemples de sujets (canon)

- harness custom
- workflows & automatisations métier
- stack chatbot dans un SaaS
- knowledge bases & intégrations
- MCP et plugins
- optimiser le dev sous IA

## Règles d’entrée (produit)

1. Compte GitHub **réel** prouvé par OAuth
2. Score ≥ **65** → rôle `member` auto
3. Score < 65 → DM refus : **score numérique only**, **zéro indice** sur les critères
4. Re-apply : **48h** après le 1er refus, puis **tous les 15 jours**
5. Profil fort mais 100 % privé → hard reject + **`#appeal`** manuel
6. Langue bot / DMs : **FR**

Détail figé : [`decisions.md`](./decisions.md).
