# Code Smells — Incubating packages (flows · tasks · comments · mcp)

**Repo:** `roxabi-boilerplate-cf`  
**Date:** 2026-08-12  
**Scope:** `packages/flows/**`, `packages/tasks/**`, `packages/comments/**`, `packages/mcp/**`  
**Domain focus:** god modules · DRY (esp. tasks↔comments twins) · dead code · over-abstraction · incomplete pure engines  
**Refs:** ADR-0005, ADR-0007, AGENTS incubating piles · axial-drift AD-S1/S2/S4/S5 (cross-check)

## Summary

Incubating packages are **small and well-factored by LOC** (no file near the ~400 quality-gate bar; largest pure engines: `flows/check.ts` ~246, `flows/runner-view.ts` ~228, `tasks/schema.ts` ~203, `mcp/index.ts` ~190). There are **no classic god modules**. The dominant smells are **intentional twin-copy between `@kit/tasks` and `@kit/comments`** (audience/visibility + enum constants), **unused or dual-path surface** (role access helpers, `AudiencePort`, mutation hooks, MCP deprecated aliases), and **incomplete engine surfaces** that are documented as incubating (flows: freeze without runner wire; MCP: decorative `effect`/`auth`; parallel tool registries vs flows). Intra-package DRY debt is mild (triple `toolNameSchema`, duplicated scope `superRefine`, dual dogfood fixtures). Overall health is good for incubating kernels; fix twins and dead dual-paths before more product composes.

## Recommendations

1. **P1 — Unify audience/visibility (F1 + F4)** before more products compose tasks+comments. Cheapest high-value smell fix; ADR-0007 already claims one model.
2. **P1 — Collapse or document tasks role helpers (F2)** so module grants remain the sole runtime power path in dogfood and products.
3. **P2 — Prune over-abstraction (F3, F9, F13):** hooks/AudiencePort without call sites; MCP deprecated aliases; identity `executionTools` helper.
4. **P2 — Intra-flows DRY (F6) + rename dual `stableStringify` (F7)** before any shared import between mcp and flows.
5. **P2 — Freeze MCP↔flows registry divergence (F8)** with a written promote checklist; no third agent registry.
6. **P2 — Sketch migrations (F11):** stop dual SSoT; one applied path only.
7. **P2 — Complete engine honesty (F10, F12):** keep pure freeze/check as the flows bar; do not grow decorative APIs; extract shared ACL rather than cloning tasks into comments.
8. **P3 hygiene:** split mega test file, single demo-echo SSoT, slim mcp entry, avoid product target enums in kit.
